# UltraNewsBot

**UltraNewsBot — multi-interface news bot with Telegram integration.**

## Description
UltraNewsBot delivers news based on selected categories.  
Supports console mode and Telegram bot with inline buttons and formatted output.  
Built with Gradle, modular, and easily extendable.

## Features
- Category-based news generation  
- RSS parsing (Lenta)  
- Local news storage  
- Multi-user support  
- Telegram integration with inline buttons  
- Console mode  

## 🛠 Installation & Run

Set the Telegram bot token as an environment variable:

In IntelliJ IDEA:

Go to Run → Edit Configurations…

Select your run configuration (e.g., Gradle run)
In Environment variables, add:

```ini
BOT_TOKEN=your_telegram_bot_token
```
